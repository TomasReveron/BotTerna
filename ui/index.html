Tutorial: Configurar Alertas en Telegram

Para recibir las alertas directamente en tu teléfono, solo debes vincular tu Telegram con estos 2 pasos:

1

Iniciar el Bot de telegram para BotTerna

Abre Telegram, busca al bot @USMternabot y presiona el botón Iniciar (o envíale /start).

¿Por qué este paso? Telegram exige por privacidad que tú inicies la conversación con el bot para autorizar el envío de alertas.
2

Obtener tu Chat ID personal

Para conocer tu número de usuario de Telegram:

  1. Busca en Telegram a @userinfobot o @myidbot.
  2. Presiona Iniciar o envíale cualquier mensaje.
  3. Te responderá con tu Id numérico (ej: 1274691002). Cópialo y pégalo en el campo Tu Chat ID de Telegram.
